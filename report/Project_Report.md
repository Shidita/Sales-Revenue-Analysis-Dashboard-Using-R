# Sales & Revenue Analysis Dashboard Using R

## 1. Introduction
The project is an interactive dashboard that uses R and Shiny to analyze sales and revenue data.

## 2. Objectives
- Analyze total sales and profit.
- Identify monthly sales trends.
- Compare categories and regions.
- Find top-performing products.
- Study the relationship between sales and profit.
- Provide interactive filtering and downloadable data.

## 3. Technologies
R, RStudio, Shiny, shinydashboard, dplyr, ggplot2, lubridate, plotly and DT.

## 4. Modules
1. Dashboard and KPI analysis
2. Monthly revenue analysis
3. Category analysis
4. Regional analysis
5. Product analysis
6. Profitability analysis
7. Data table and export
8. Project information

## 5. Methodology
The CSV dataset is imported using base R. Dates and numeric fields are converted to suitable data types. dplyr is used for filtering, grouping and aggregation. ggplot2 creates the charts and plotly makes them interactive. Shiny connects the controls and visualizations.

## 6. Expected Outcome
The dashboard helps users quickly identify revenue trends, profitable categories, strong regions and high-performing products.
